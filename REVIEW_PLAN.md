## PHASE 2: REVIEW FRAMEWORK

### A. ENGAGEMENT METRICS (Video Game Standards)

| Criterion | Question | Target |
|-----------|----------|--------|
| **Hook Quality** | Does the opening grab attention in <10 words? | 100% of lessons |
| **Bizarreness** | Is the imagery weird enough to stick? (1-5 scale) | Avg 4+ |
| **Emotional Valence** | Does it evoke emotion (humor, disgust, surprise)? | 90%+ |
| **Flow State** | Does pacing maintain engagement without cognitive overload? | Check per lesson |
| **Memorable Moments** | Are there 2-3 "peak" moments per story? | Yes/No per lesson |

### B. LEARNING EFFECTIVENESS (EdGame Standards)

| Criterion | Question | Target |
|-----------|----------|--------|
| **Character Coverage** | Are ALL characters in the lesson woven into narrative? | 100% |
| **Keyword Prominence** | Is each keyword bolded and positioned memorably? | 100% |
| **Spatial Anchoring** | Can readers visualize WHERE things happen? | 80%+ |
| **Causal Chains** | Do events connect logically (even if absurdly)? | 90%+ |
| **Retrieval Cues** | Does the story provide multiple paths to recall each character? | 2+ cues per char |

### C. PROGRESSION DESIGN (Game Difficulty Curve)

| Criterion | Question | Target |
|-----------|----------|--------|
| **Lesson Length** | Does story length match character count appropriately? | Proportional |
| **Complexity Scaling** | Do later lessons build on earlier concepts? | Check callbacks |
| **Callback Density** | Are connections between lessons strengthening memory? | 50+ callbacks |
| **Saga Coherence** | Do saga groupings (Genesis, Empire, etc.) feel thematic? | Evaluate |

### D. NARRATIVE QUALITY (Storytelling Standards)

| Criterion | Question | Target |
|-----------|----------|--------|
| **Protagonist Clarity** | Is there a clear "main character" to follow? | 90%+ |
| **Conflict Present** | Is there tension/problem/goal? | 100% |
| **Resolution Satisfying** | Does the ending feel complete? | 90%+ |
| **Voice Consistency** | Is the absurdist tone maintained throughout? | 100% |
| **Cliche Avoidance** | Are we avoiding tired tropes? | Evaluate |

## PHASE 3: SPECIFIC REVIEW TASKS

### Task 1: Hook Audit
Review all 55 hooks for:
- [ ] Active voice (not "decided to" or "wanted to")
- [ ] Specific imagery (not vague)
- [ ] Immediate intrigue
- [ ] Character count <15 words

### Task 2: Character Coverage Verification
For each lesson:
- [ ] Count characters in story vs. source data
- [ ] Flag any missing characters
- [ ] Flag any duplicates

### Task 3: Bizarreness Scoring
Rate each lesson 1-5:
1. Mundane - forgettable
2. Slightly odd - might remember
3. Unusual - will probably remember
4. Bizarre - will definitely remember
5. Unforgettable - peak mnemonic

### Task 4: Callback Network Analysis
Map all callbacks:
- [ ] Identify isolated lessons (no connections)
- [ ] Identify over-connected lessons (too many callbacks)
- [ ] Check callback balance across sagas

### Task 5: Cognitive Load Assessment
For lessons with 40+ characters:
- [ ] Is story segmented into digestible chunks?
- [ ] Are there "rest points" in the narrative?
- [ ] Is information density manageable?

### Task 6: Retrieval Cue Audit
Sample 10 random characters:
- [ ] Can you recall the character from the story context alone?
- [ ] Are there multiple pathways to the memory?
- [ ] Does the keyword appear in a memorable action/image?

## PHASE 4: SCORING RUBRIC

### Overall Quality Score (100 points)

| Category | Weight | Criteria |
|----------|--------|----------|
| Engagement | 25 pts | Hook quality, bizarreness, emotional impact |
| Learning | 30 pts | Coverage, retrieval cues, spatial anchoring |
| Progression | 20 pts | Callbacks, scaling, saga coherence |
| Narrative | 25 pts | Protagonist, conflict, resolution, voice |

### Per-Lesson Grades

- **A (90-100)**: Publishable as-is
- **B (80-89)**: Minor tweaks needed
- **C (70-79)**: Significant revision needed
- **D (60-69)**: Major rewrite required
- **F (<60)**: Start over

---

## PHASE 5: REVISION PRIORITIES

After scoring, prioritize fixes by:

1. **Critical** (must fix): Missing characters, broken narrative
2. **High** (should fix): Weak hooks, low bizarreness, no callbacks
3. **Medium** (nice to fix): Pacing issues, weak resolutions
4. **Low** (polish): Voice consistency, minor cliche removal
